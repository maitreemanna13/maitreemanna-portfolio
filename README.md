# Maitree Manna — Portfolio

Personal portfolio site for Maitree Manna, Data Architect & Senior Data Engineer.
Plain HTML/CSS/JS — no build step, deploys directly to GitHub Pages.

## Structure

```
index.html        Page markup and content
css/styles.css     Theme, layout, responsive styles
js/main.js         Mobile nav toggle, scroll-reveal animations
```

## Run locally

Open `index.html` directly in a browser, or serve it:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `portfolio`).
2. Push this project to it (see commands printed after setup).
3. On GitHub: **Settings → Pages → Source → Deploy from branch → `main` / root**.
4. Site will be live at `https://<username>.github.io/<repo>/`.
